Install Workdeck

brew install --HEAD ruttydm/workdeck/workdeck

Nix

nix run github:ruttydm/workdeck -- --help

Source checkout

cargo install --path crates/workdeck-cli --locked
workdeck

Inside the review canvas

See the workbench in motion.

One stream, every file.

The whole changeset reads top to bottom in sidebar order—no flipping between single-file views. File counts stay visible, hunk jumps remain quick, and the sidebar takes you straight to any file.

How reviews work →

Your agent's reasoning, beside the code it explains.

Agents leave notes in a sidecar; Workdeck renders each one inside the diff, right above the hunk it annotates—summary, rationale, and author.

Agent annotations, in depth →

Keys when you're fast, mouse when you're browsing.

Click a file in the sidebar to jump, wheel-scroll the stream, hover a row to leave a note—or never leave the keyboard. Pipe patches straight in and Workdeck is your pager, too.

Keyboard & mouse reference →

Split or stack—or let auto decide.

Side-by-side when your terminal is wide, stacked when it's narrow. Auto picks for you; change layouts at any time, with wrapping and line numbers toggled live.

Layout & display options →

Real syntax highlighting. Dozens of themes.

Understand structure, not just added and removed lines. Workdeck ships readable palettes—Catppuccin, Dracula, Gruvbox, GitHub, and more—or you can roll your own.

Theme gallery & config →

Extend it however you want.

Add a theme, command, file preview, docked pane, or version-control backend. Extensions are native Rust subprocesses with a bounded JSON-RPC contract.

Writing extensions →

No JavaScript runtime

The application, review model, syntax pipeline, sessions, extension host, packaging tools, and site pipeline are Rust-native. User extensions are explicit native subprocesses speaking bounded JSON-RPC over stdio.

Auditable semantic port

Every pinned Hunk blob is tracked in a byte-exact ledger until its Rust implementation, translated tests, content, asset, or generated replacement is verified.
