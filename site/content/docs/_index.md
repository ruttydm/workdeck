Workdeck is a terminal diff reviewer for complete changesets, with durable
review notes and agent context beside the code it explains. Use this page to
jump directly to the guide or reference you need.

## New to Workdeck?

1. [Install Workdeck](/docs/start/install/).
2. Open your working tree with `workdeck diff` or run `workdeck` for the unified
   Review-first shell.
3. Follow the [quick start](/docs/start/quick-start/) to learn the review stream,
   panes, and navigation model.
