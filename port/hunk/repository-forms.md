## Raw-byte correction

The guide reconstruction test exposed that the generic `git_stdout` helper trims
whitespace. The earlier three generated artifacts consequently lacked their final
source newline despite the byte-preservation claim. This pipeline now exclusively
reads `git_stdout_bytes`, decodes UTF-8 without trimming, and regenerates the
artifacts with those newlines restored. A regression checks all four exact source
lengths, final newlines and entire generated byte sequences. No normalization or
waiver is used to hide the discrepancy. Complete-byte checks and scoped Clippy
pass after the correction; GitHub deployment and full-port gates remain separate.
The native CI matrix now fetches preserved upstream evidence on every test host,
not only Linux x64, because these source-backed tests require both repositories'
objects locally. The local setup prerequisite is documented in README. This is a
CI configuration change, not evidence that the remote native matrix has run.
